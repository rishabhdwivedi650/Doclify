# Doclify

A simple Generative AI based CLI tool that helps generate documentation for software projects.

## Features

- Reads source code files from a project
- Uses Generative AI to understand the code
- Generates a simple project README
- Supports common programming languages

## Technologies Used

- Python
- Generative AI
- Groq API
- Prompt Engineering
